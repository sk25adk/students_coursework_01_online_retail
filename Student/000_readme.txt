Online Retail and Stock Management

15 independent tasks; 100 marks.

1. Prepare your Oracle account
Use the account assigned by your tutor, before installing this coursework for the first time. Extract the package. Keep SetupCourseWork.sql, CourseWorkDB.sql and SeedData.sql together in its top-level folder. Run SetupCourseWork.sql once before any task; do not rerun setup between tasks. Setup receives no assessment marks.
In SQL Developer, connect to the Oracle account assigned by your tutor before installing this coursework. In a SQL worksheet, enter @"C:\Coursework\SetupCourseWork.sql" (replace the example with the full path to your extracted file), then press F5 (Run Script). Use Run Script rather than Run Statement (Ctrl+Enter). Check Script Output for errors before starting any task.

2. Complete and save a task
Open a numbered SQL file in Student and read its requirement, object name, interface and total marks. Keep the supplied session identifier block and its TODO comment. Write your answer below the block END; and the following / line. Save the SQL file, run it in your assigned Oracle account, correct errors and save again. Keep every supplied filename unchanged.

3. Test your installed object
Use your own SQL against the rows in the supplied tables. Each task has its own tables and can be attempted in any order; do not use another task answer. Do not include COMMIT in procedures or triggers. The calling program decides when to commit. Undo temporary test changes with ROLLBACK, using a SAVEPOINT where needed to mark the point to return to. Oracle table and object definition statements commit implicitly; ROLLBACK does not undo those definitions.

4. Submit your work
Record your student ID and assigned Oracle username. Save your final numbered SQL files. Follow the deadline and submission method given by your tutor.
